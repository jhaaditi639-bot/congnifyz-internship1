## 🐍 Level 2 Tasks

### Task 1 – Guessing Game
A Python program that generates a random number between 1 and 100.  
The user tries to guess the number, and the program provides hints such as:
- Too high
- Too low
- Correct guess

### Task 2 – Number Guesser
A number guessing game where the program generates a random number within a specified range.  
The user enters guesses and receives feedback if the guess is too high or too low.

### Task 3 – Password Strength Checker
A Python program that checks the strength of a password based on:
- Password length
- Uppercase letters
- Lowercase letters
- Digits
- Special characters

### Task 4 – Fibonacci Sequence
A Python function that generates the Fibonacci sequence up to the number of terms entered by the user.

### Task 5 – File Manipulation
A Python program that reads a text file, counts the occurrences of each word, and displays the words in alphabetical order along with their counts.

## 🛠️ Technologies Used

- Python
- Random Module
- File Handling
- Functions
- Loops
- Conditional Statements
